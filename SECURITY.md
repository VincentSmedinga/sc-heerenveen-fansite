# Een kwetsbaarheid melden

Heb je een kwetsbaarheid gevonden in de sc Heerenveen Fansite?
Fijn dat je het meldt.
Lees eerst hieronder wat je kunt verwachten en wat we van je vragen.

## Waar je meldt

Meld een kwetsbaarheid bij voorkeur via de privémelding van GitHub.
Ga naar het tabblad Security van de repository en kies "Report a vulnerability".
Heb je geen GitHub-account, mail dan naar `fansite@heerenveen.org`.

Meld een kwetsbaarheid niet in een openbaar issue en niet op het forum.
Dan kan iedereen haar lezen voordat we haar hebben verholpen.

## Wat valt eronder

Dit beleid geldt voor wat op de site draait: de actuele `main`, zoals die op heerenveen.org staat, en de code ervan in deze repository.
Oudere versies en forks vallen erbuiten, evenals het forum, dat een eigen repository heeft.

We horen het liefst van kwetsbaarheden in de twee inlogs, die van het beheer en die van de fans.
Wij zien deze dingen als een kwetsbaarheid:

- toegang tot een account of tot de beheerpagina's zonder in te loggen;
- gegevens van anderen kunnen inzien;
- geheimen die in de code of in het logboek staan;
- de herinnering van een ander uitzetten of een link voor een ander account maken: de link in een herinnering heeft een code met een ondertekening van de server (`FANS_REMINDER_SECRET`).

## Wat we beloven

We bevestigen je melding en laten weten wat we eraan doen.
We noemen geen vaste termijn, want dit is een project van vrijwilligers.
We beloven ook geen beloning en geen vaste hersteltijd.

## Wat we van je vragen

Handel te goeder trouw:

- Bekijk of bewaar geen gegevens van anderen.
- Doe geen aanval die de site voor anderen onbruikbaar maakt.
- Stuur geen spam en pleeg geen social engineering naar bezoekers of de redactie.

Houd je je daaraan, dan pakken we je niet aan.
