# Componenten

De React-componenten van het designsysteem.
Elk onderdeel heeft hieronder een eigen pagina, met voorbeelden in licht en donker.
Een sjabloon voor een pagina bevat geen HTML, alleen deze componenten.

Dit zijn de eerste negen, met de drie onderdelen van `Page`: wat een pagina minimaal nodig heeft.
Knoppen, pictogrammen en de componenten voor nieuws, bronnen, podcasts, het forum en wedstrijden komen met de eerste pagina die ze nodig heeft.

## Gebruiken

Het package geeft de componenten als TypeScript-bronbestanden, zonder eigen bouwstap.
De site compileert ze mee (in Next.js met `transpilePackages`).
Importeer de componenten uit het package, en de stijlen uit `index.css`:

```tsx
import { Heading, Page } from '@fansite/design-system'
```

```css
@import url('@fansite/design-system/index.css');
```

## Een pagina bouwen

`Root` en `Body` zijn de `html` en de `body`.
`Page` bevat een `Page.Header`, een `Page.Body` en een `Page.Footer`, in die volgorde.
De `main` van de pagina is de `Page.Body` zelf, of zit erin.

```tsx
<Root>
  <Body>
    <Page>
      <Page.Header>
        <Link href="/">
          <Logo />
        </Link>
        <Navigation items={menu} label="Hoofdmenu" />
      </Page.Header>
      <Page.Body>
        <Heading level={1}>Nieuws</Heading>
        <Text>…</Text>
      </Page.Body>
      <Page.Footer>
        <Text appearance="meta">…</Text>
      </Page.Footer>
    </Page>
  </Body>
</Root>
```

De `head` hoort niet bij de componenten: die beheert Next.js, met de Metadata API.

## Afspraken

- **Attributen:** elk component neemt de attributen van zijn element over, zoals `id`, `lang` en `aria-*`.
  Een `className` komt bij de klassen van het component.
  Alleen wat een component zelf vastlegt, geef je niet mee: de `lang` van `Root` en de naam van `Navigation` en `Logo`.
- **Het element kiezen:** waar een component meer dan één element kan zijn, kies je met `as` uit een vaste lijst.
  De typen laten geen ander element toe.
- **Onderdelen met een punt:** een onderdeel dat bij één oudercomponent hoort, schrijf je met een punt achter die ouder, ook als het element buiten die ouder wel geldig is.
  Een item van een lijst is `List.Item`, want een `li` hoort in een `ul` of `ol`.
  De header, de inhoud en de footer van een pagina zijn `Page.Header`, `Page.Body` en `Page.Footer`.
- **Klassen:** de componenten gebruiken de klassen met het voorvoegsel `hf-` en zitten in de laag `hf.components`.
- **Niveau en stijl:** het niveau van een kop volgt de structuur van de pagina, de stijl het ontwerp.
  Zie [Heading](?path=/docs/componenten-heading--documentatie).

Tot er meer componenten zijn, staan de stijlen voor gewone HTML onder [HTML-elementen](?path=/docs/html-elementen-koppen--documentatie).
